LiaScript Slide Templates

Slide templates in 9 families for interactive teaching with LiaScript – two sets of 27: the reviewed, render-tested set and a set generated by a local model (gx10) from the same rules. Switch below. Each link opens the template directly in LiaScript: the first page is its fill guide, the following pages show the slides.

Build a whole session from a plain-text content file with assemble.py – no LiaScript or code editing needed.
